About

GiraffeOS is an experimental, tall‑architecture operating system built for creativity, exploration, and custom kernel development. Inspired by the elegance and long‑reach design of giraffes, GiraffeOS combines the Linux kernel with a flexible Python‑powered userland.

Our mission is to build an OS that “stands above the rest” — with clear structure, modular components, and a playful identity. GiraffeOS is open‑source, community‑friendly, and designed for learners, tinkerers, and OS enthusiasts.

Projects include:

  • 🦒 GiraffeOS Kernel — the Linux kernel, customised and stripped

  • 🐍 Userland — Python utilities, shell, and tools

  • 🎨 Art & Mascots — logos, themes, and Smooth Emoji assets

  • 📦 Build System — scripts, packaging, and ISO generation

  • 📚 Documentation — guides, specs, and OS lore

GiraffeOS is built by people who love tall mascots, weird OS experiments, and learning how computers work from the inside out.
